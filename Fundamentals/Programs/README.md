# C Practice Programs Playground 💻

This folder is my personal practice lab where I save all the daily code scripts, lab exercises, and experimental text programs I write in VS Code while mastering the absolute fundamentals of C.

## 🗂️ Lab Code Index

### 1. **[hello_world.c](./hello_world.c):** 
The absolute basic skeleton of a C program. Teaches how to include the header file (`stdio.h`), use the `main()` function structure, and print text to the screen.

## 🛠️ How I Compile These Exercises
To compile and test any of these practice programs on your terminal, open your command window and run:

```bash
# Compile command
gcc filename.c -o file_name

# Run command
./file_name
```
